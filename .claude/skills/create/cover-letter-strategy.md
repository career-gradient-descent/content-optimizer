# Cover Letter Strategy

One page, opportunity-specific. The exact person who will read it is unknown (unless found out by research), so it argues fit for the role and the company, not to a named individual. Voice from `voice.local.md`, warmed half a degree for a letter.

Address the company or its hiring team only when recon confirms the employer. For an agency-mediated role, or an employer recon only deduced rather than confirmed, do not name a client you cannot stand behind: leave the addressee generic and keep the letter fit-forward for whoever reads it first.

Hyperlinks (GitHub, LinkedIn, project URLs) add real value but cannot be expressed at the YAML level. After rendering, edit the rendered `.tex` to add them, then re-render that `.tex` (`co render …/cover-letter.tex`). Re-rendering the YAML instead would regenerate the `.tex` and wipe the edits.
